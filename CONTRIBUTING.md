# Contributing

Use Rust 1.88 or newer. Keep changes small, add regression tests for changed invariants, and run `./scripts/verify.sh` before opening a pull request. Never weaken privacy-tier checks, introduce a CCU transfer path, expose ambient Wasm capabilities, or commit real user data or secrets.

By participating, you agree to the Code of Conduct. Security vulnerabilities belong in private reports described in `SECURITY.md`.

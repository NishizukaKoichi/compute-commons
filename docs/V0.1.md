# v0.1 implementation contract

Date: 2026-08-09

## Scope

The v0.1 reference implementation demonstrates the target specification's Research MVP on one machine using only public or synthetic data. It is a reproducible safety model and CLI, not a production distributed network.

## Evidence

| Target property | Evidence |
|---|---|
| Approved, immutable packages only | Signature and digest verification in `Registry`; tamper test |
| No ambient host capabilities | Wasmtime module imports must be empty; WASI import rejection test |
| No privacy downgrade | P2/P3/P4 and local-only remote submission fail closed |
| Resource and operator control | Capability fit, pause, drain, and revocation checks before lease |
| Failure recovery | Expired lease returns an unfinished task to the queue |
| Deterministic verification | Exact expected output check rejects an incorrect result |
| Non-financial CCU | Fixed reference cost, no transfer operation, no wall-time multiplier |
| No duplicate CCU | Task ID settlement is idempotent |
| Auditable control plane | Hash-linked events and signed audit root |
| Replay resistance | Unique request ID and maximum five-minute validity window |

## Explicitly not implemented

Remote networking, relay fallback, encrypted blob persistence, desktop UI, multi-node quorum, governance, TUF/Sigstore/SLSA release infrastructure, TEE attestation, guardian key release, GPU execution, and P4 cryptographic plans. These remain later milestones and are never simulated as security guarantees.

## Verification

Run `./scripts/verify.sh`. The command checks formatting, lint, tests, release build, the end-to-end demo, and repository secret patterns.

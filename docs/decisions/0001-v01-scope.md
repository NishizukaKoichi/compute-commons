# ADR 0001: public-data Wasm research MVP

- Date: 2026-08-09
- Status: accepted

## Decision

Implement the target specification's v0.1 as a Rust domain core and CLI with capability-free Wasmtime execution. Unsupported privacy tiers fail closed. Use public or synthetic inputs only.

## Why

This is the smallest honest, executable slice that proves package approval, scheduling, operator controls, verification, CCU invariants, and auditability without claiming unavailable hardware protections.

## Alternatives considered

A UI-first mock would look complete without enforcing core invariants. Implementing TEE or GPU paths without qualified hardware and independent review would create false security claims.

## Risks and rollback

Wasmtime increases build size and remains a security-sensitive dependency. Pin releases through `Cargo.lock`, run dependency review before releases, and remove the runtime crate if a critical issue cannot be mitigated. Reverting this ADR and its initial commit removes the new repository cleanly.
